# 个人博客系统 PRD（MyBlog）

> 本文档为开发需求说明，可直接交给 Claude Code 按此实现。

## 1. 产品概述

### 1.1 项目名称
个人博客系统（MyBlog）

### 1.2 项目目标
- 搭建一个可供博主发布文章、读者浏览阅读的个人博客网站
- 提供独立的管理后台，博主无需技术背景即可通过网页管理文章内容

### 1.3 核心价值
- 对博主：低门槛的内容发布与统一管理，后台仪表盘随时掌握博客数据概况
- 对读者：简洁清晰的阅读体验，快速浏览并阅读感兴趣的文章

## 2. 目标用户

| 用户角色 | 描述 | 核心诉求 |
|---------|------|---------|
| 博主（管理员） | 博客所有者，负责内容生产与维护 | 发布/编辑/删除文章，查看文章统计数据 |
| 读者（访客） | 浏览博客的普通互联网用户 | 快速找到并阅读感兴趣的文章，了解博主 |

## 3. 功能需求

### 3.1 用户端（前台）

#### 3.1.1 首页
**功能描述**
- 以发布时间倒序展示文章列表，支持分页
- 点击文章卡片进入文章详情页
- 顶部导航可在"首页 / 关于我"之间切换

**页面组件**
- 顶部导航栏：站点名称/Logo、导航链接（首页、关于我）
- 文章列表：文章卡片（标题、摘要、发布时间、分类/标签）
- 分页器
- 页脚：版权信息

**验收标准**
- 文章按发布时间倒序排列；每页展示固定条数，可翻页
- 无文章时展示空状态提示

#### 3.1.2 文章详情页
**功能描述**
- 展示文章完整内容（标题、正文、发布时间、分类/标签）
- 支持返回首页

**页面组件**
- 顶部导航栏（同首页）
- 文章标题
- 文章元信息（发布时间、分类/标签）
- 文章正文（支持 Markdown 渲染）
- 返回按钮

**验收标准**
- 正文以 Markdown 渲染；文章不存在时展示 404 提示

#### 3.1.3 关于我页面
**功能描述**
- 展示博主自我介绍、联系方式、社交链接

**页面组件**
- 顶部导航栏（同首页）
- 博主头像
- 自我介绍文字
- 联系方式 / 社交链接列表

### 3.2 博主管理后台

#### 3.2.1 管理员登录
**功能描述**
- 账号 + 密码登录
- 登录成功进入后台仪表盘；失败给出明确错误提示
- 未登录访问后台任意页面时，重定向到登录页

**页面组件**
- 登录表单：账号输入框、密码输入框、登录按钮
- 错误提示信息

**验收标准**
- 密码校验通过后跳转仪表盘；校验失败提示"账号或密码错误"
- 未登录直接访问后台 URL 时被重定向到登录页

#### 3.2.2 后台仪表盘
**功能描述**
- 展示文章统计数据，作为后台默认首页

**页面组件**
- 后台布局：侧边栏导航（仪表盘、文章管理）、顶部栏（退出登录按钮）
- 统计卡片：文章总数、已发布数量、草稿数量、最近发布文章

**验收标准**
- 统计数据与文章实际数据一致；退出登录后跳回登录页

#### 3.2.3 文章管理（CRUD）
**功能描述**
- 文章的列表、新增、编辑、删除

**页面组件**
- 文章列表表格：标题、状态（已发布/草稿）、发布时间、操作列（编辑、删除）
- 新增/编辑表单：标题、摘要、正文（Markdown 编辑）、分类/标签、发布状态
- 删除二次确认弹窗

**验收标准**
- 新增/编辑后列表数据实时更新；删除需二次确认，删除后不可恢复
- 保存草稿不展示在用户端，发布后才在首页可见

### 3.3 文章数据模型（参考）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string/number | 主键 |
| title | string | 标题 |
| summary | string | 摘要 |
| content | string | 正文（Markdown） |
| category | string | 分类 |
| tags | string[] | 标签 |
| status | enum | draft（草稿）/ published（已发布） |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### 3.4 访问权限清单

#### 3.4.1 页面访问权限

| 路由 | 谁能访问 | 规则 |
|------|---------|------|
| `/` 首页 | 任何人 | 只展示"已发布"文章 |
| `/post/:id` 文章详情 | 任何人 | 草稿文章即使知道链接也返回 404 |
| `/about` 关于我 | 任何人 | — |
| `/admin/login` 后台登录 | 任何人 | 已登录时访问则跳转仪表盘 |
| `/admin` 仪表盘 | 仅管理员 | 未登录重定向到登录页 |
| `/admin/posts` 文章列表 | 仅管理员 | 同上 |
| `/admin/posts/new` 新增文章 | 仅管理员 | 同上 |
| `/admin/posts/:id/edit` 编辑文章 | 仅管理员 | 同上 |

#### 3.4.2 接口访问权限

| 接口 | 谁能调用 |
|------|---------|
| `POST /api/auth/login` 登录 | 任何人（校验账号密码） |
| `POST /api/auth/logout` 退出 | 仅已登录 |
| `GET /api/posts` 后台列表（含草稿） | 仅管理员 |
| `POST /api/posts` 新增 | 仅管理员 |
| `PUT /api/posts/:id` 编辑 | 仅管理员 |
| `DELETE /api/posts/:id` 删除 | 仅管理员 |

#### 3.4.3 实现约定
- 页面层：全局中间件拦截所有 `/admin/*` 路径，白名单仅 `/admin/login`；未登录访问后台页面 302 重定向到登录页，已登录访问登录页则跳转仪表盘
- 接口层：每个后台接口内部校验会话，未登录返回 401（真正的安全防线，页面重定向仅为体验）
- 数据层：前台所有查询强制 `status = published`，草稿对前台完全不可见

## 4. 非功能性需求

### 4.1 响应式设计
- 用户端所有页面适配桌面端、平板、手机三种尺寸
- 断点建议：≥1024px 桌面端；768–1023px 平板；<768px 手机
- 手机端导航折叠为汉堡菜单，文章列表单列展示
- 后台以桌面端为主，保证 ≥1024px 下正常使用（可做基础适配）

### 4.2 安全
- 登录密码加密存储，禁止明文
- 后台所有接口需鉴权，未登录请求返回 401

### 4.3 性能与兼容
- 首页采用分页加载，避免一次性全量加载文章
- 兼容 Chrome、Edge、Firefox、Safari 等主流现代浏览器

### 4.4 页面路由约定（建议）

| 页面 | 路由 |
|------|------|
| 首页 | `/` |
| 文章详情 | `/post/:id` |
| 关于我 | `/about` |
| 后台登录 | `/admin/login` |
| 仪表盘 | `/admin` |
| 文章管理 | `/admin/posts` |
